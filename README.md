# Usta

Usta sifarişi xidməti (Profi.ru üslubunda): müştəri xidmət kateqoriyasını seçir, problemi qısaca yazır, ünvan və mobil nömrə qoyur və sifariş göndərir. Redaktorlar «Daxil olanlar» bölməsində sifarişləri görür və statusunu dəyişir (Yeni / İcrada / Hazırdır).

- `index.html` — bütün tətbiq (HTML + CSS + JS bir faylda)
- Sifarişlər claude.ai Artifact `db` imkanında saxlanılır (`requests/<userId>` sənədləri).
